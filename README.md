# TGPA-Project---OCR-License-Plate-Recognition-
Automatic License Plate Recognition (ALPR) – Prototype Demo

Developed in collaboration with Telangana State Police Academy (TGPA)

This repository contains a demo video of an ALPR prototype built for TGPA. Due to confidentiality and data-security requirements, the source code, datasets, and backend implementation cannot be shared publicly.

Project Overview:
A Python-based ALPR system designed to:
Detect vehicle license plates from uploaded images
Extract text using OCR (EasyOCR/Tesseract)
Log plate numbers, timestamps, and inference times to a secure backend
Provide a real-time Streamlit interface for operational use

Prototype Demo:
TGPA-Prototype.mp4 demonstrates the complete workflow, including plate detection, OCR extraction, and result visualization.

Tech Stack:
Python 
OpenCV 
EasyOCR 
Tesseract 
Streamlit 
MySQL

Confidentiality Notice:
The full implementation is restricted due to the collaboration with TGPA. This repository includes only the execution video and a high-level summary.
